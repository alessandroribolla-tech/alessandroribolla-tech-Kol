# Export interazioni

Per settimana ISO creare `inputs/interazioni/<YYYY-Wnn>/` e depositare:
- Meta Business Suite → Insights → Esporta dati (contenuti + pubblico), CSV per IESS e iRES.
- Commenti e messaggi: esporta o incolla in `commenti.md` (canale, data, autore, testo).
- LinkedIn pagina → Analytics → Esporta (aggiornamenti, follower, visitatori) XLS.
- YouTube Studio → Analytics → Esporta CSV.
In alternativa `/pubblica analytics` salva qui i dati letti da Postiz.
