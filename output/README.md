# Output degli agenti
Ogni deliverable ha frontmatter con `stato` (bozza → in_revisione → approvato → programmato/pubblicato) e `compliance`. Per approvare: modificare `stato: approvato` nel file. `scripts/stato.sh [settimana]` mostra il quadro.

| Cartella | Deliverable |
|---|---|
| `report-concorrenza/` | `<SETT>.md` |
| `piani-editoriali/` | `<SETT>.md` |
| `post-social/<SETT>/` | un file per post + `creativita/` |
| `newsletter/` | `<SETT>-<lista>.md` |
| `sito/` | `<SETT>-<slug>.md` |
| `sponsorizzate/` | `<SETT>.md` |

| `risultati/` | `<SETT>.md` settimanale, `<YYYY-MM>.md` + `-dati.csv` mensile |
| `cataloghi/` | struttura e testi di cataloghi e media kit |
| `packaging/` | brief e checklist packaging ed etichette |
| `riepilogo/` | `<SETT>-brief.md` (priorità del capo), `<SETT>.md` (decisioni e cose da approvare), `decisioni.md` (registro cumulativo) |
